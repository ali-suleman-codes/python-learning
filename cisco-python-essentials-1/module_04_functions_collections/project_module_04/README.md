# 🎮 Tic-Tac-Toe Game

## 📌 Overview

This project is my **Module 04 Milestone Project** for the **Cisco Networking Academy – Python Essentials 1** course.

The program implements a console-based Tic-Tac-Toe game where the player competes against the computer. It validates user input, generates random computer moves, detects winning combinations, and determines when the game ends in a draw.

The purpose of this project is to apply all major concepts learned throughout **Module 04 (Functions, Tuples, Dictionaries and Exceptions)** by building a complete interactive Python application.

---

## 🎯 Project Goal

Build a complete Python application using only the concepts covered in **Module 04**, demonstrating the ability to:

* Organize code into reusable functions
* Validate user input
* Handle runtime errors using exception handling
* Store and process game data
* Generate random computer moves
* Implement game logic
* Build an interactive console application

---

## ✨ Features

* Interactive Tic-Tac-Toe gameplay
* Computer starts with the center square occupied
* Random computer moves
* User input validation
* Prevents selecting occupied squares
* Detects row, column and diagonal wins
* Detects draw situations
* Handles invalid input using exception handling
* Gracefully exits when interrupted with **Ctrl + C**
